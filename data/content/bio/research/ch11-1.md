# 11.1: The Chi-Square Test
## Hypothesis Testing, Observed vs. Expected, and Statistical Significance


            <div class="lesson-section">

                <div class="key-terms-box glass" style="border-left: 4px solid var(--accent-red); padding: 20px; margin-bottom: 30px; border-radius: var(--standard-radius);">
                    <h4 style="color: var(--accent-red); margin-bottom: 12px;"><i class="fas fa-key"></i> Key Terms</h4>
                    <div style="display: grid; grid-template-columns: 1fr 1fr; gap: 8px; font-size: 0.9rem;">
                        <div><strong>Null Hypothesis (H₀)</strong> — States there is no significant difference between observed and expected results.</div>
                        <div><strong>Alternative Hypothesis (Hₐ)</strong> — States there IS a significant difference; the null is rejected.</div>
                        <div><strong>Chi-Square (χ²)</strong> — A statistical test comparing observed data to expected data: χ² = Σ[(O−E)²/E].</div>
                        <div><strong>Degrees of Freedom</strong> — df = number of categories − 1. Used to find the critical value in the chi-square table.</div>
                        <div><strong>P-value</strong> — Probability that the results are due to chance alone. Standard threshold: p = 0.05 (5%).</div>
                        <div><strong>Critical Value</strong> — The chi-square value at the p = 0.05 threshold for a given df. If χ² > CV, reject H₀.</div>
                    </div>
                </div>

                <div class="intuition-box glass" style="border-left-color: var(--accent-red);">
                    <h3><i class="fas fa-lightbulb"></i> Big Idea: Is Your Data Real or Random?</h3>
                    <p>Science doesn't prove things — it <strong>disproves</strong> them. The chi-square test asks: "Could this result have happened by chance?" If the answer is "yes" (p > 0.05), we <strong>fail to reject</strong> the null hypothesis. If "no" (p < 0.05), we <strong>reject the null</strong> — our results are statistically significant.</p>
                </div>

                <h2>I. The Chi-Square Formula</h2>
                <p style="text-align: center; font-size: 1.2rem; margin: 25px 0; font-family: 'JetBrains Mono', monospace;">
                    χ² = Σ [(Observed − Expected)² / Expected]
                </p>

                <h2>II. Step-by-Step Procedure</h2>
                <ol style="line-height: 2.2;">
                    <li><strong>State the null hypothesis:</strong> "There is no significant difference between observed and expected ratios."</li>
                    <li><strong>Calculate expected values</strong> based on the predicted ratio (e.g., 3:1 Mendelian ratio).</li>
                    <li><strong>Apply the formula</strong> for each category and sum the results.</li>
                    <li><strong>Determine degrees of freedom:</strong> df = (number of categories) − 1.</li>
                    <li><strong>Compare χ² to the critical value</strong> at p = 0.05.</li>
                    <li><strong>Conclude:</strong> If χ² > CV → reject H₀ (significant). If χ² < CV → fail to reject H₀ (not significant).</li>
                </ol>

                <div class="example-card glass" style="padding:20px; border-radius:var(--standard-radius); margin:25px 0; border-left:3px solid var(--accent-red);">
                    <h5 style="color: var(--accent-red); margin-bottom:8px;"><i class="fas fa-pencil-alt"></i> Worked Example: Mendelian Genetics Chi-Square</h5>
                    <p style="font-family:'JetBrains Mono', monospace; background:rgba(0,0,0,0.2); padding:10px; border-radius:8px; margin-bottom:12px;">You cross Aa × Aa and observe 310 tall, 90 short (total = 400). Expected 3:1 ratio. Is the deviation significant?</p>
                    <details>
                        <summary style="font-size:0.85rem; color:var(--accent-red); font-weight:600; cursor:pointer;">View Solution</summary>
                        <div style="margin-top:10px; padding-left:15px; border-left:1px solid rgba(255,255,255,0.1); line-height:2;">
                            <div><strong>Step 1:</strong> Expected: Tall = 300, Short = 100.</div>
                            <div><strong>Step 2:</strong> χ² = (310−300)²/300 + (90−100)²/100 = 100/300 + 100/100 = 0.33 + 1.00 = <strong>1.33</strong></div>
                            <div><strong>Step 3:</strong> df = 2 − 1 = 1</div>
                            <div><strong>Step 4:</strong> Critical value (df=1, p=0.05) = 3.84</div>
                            <div style="margin-top:8px; color:var(--accent-red); font-style:italic;">1.33 < 3.84 → Fail to reject H₀. The deviation is due to chance. The 3:1 ratio is supported.</div>
                        </div>
                    </details>
                </div>

                <div class="glass-card" style="border-left: 4px solid var(--accent-red); padding: 20px; margin-top: 30px;">
                    <h4><i class="fas fa-clipboard-check"></i> Summary</h4>
                    <ul style="line-height: 2; font-size: 0.92rem;">
                        <li>Chi-square tests whether observed data fits expected ratios.</li>
                        <li>Formula: χ² = Σ[(O−E)²/E]. df = categories − 1.</li>
                        <li>If χ² > critical value at p = 0.05 → reject H₀ (significant result).</li>
                        <li>If χ² < critical value → fail to reject H₀ (result consistent with hypothesis).</li>
                    </ul>
                </div>
